MemStore_v2 — Architecture Map

Fully model-free durable memory for agents: LMDB + Tantivy, no neural models, offline, startup <1 s. This page is the visual companion to docs/architecture.md.

4 · Search, step by step

#StageWhat happens
1mode classifyexact (identifiers) vs hybrid; "semantic" is honored as hybrid (no models).
2candidatesTantivy/BM25 over the normalized terms field (k×5 docs, BM25 scoring).
3graph expand<20 candidates → 1-hop neighbors via adjacency.
4rerankbase ×(1+keyword+sparse learned) + (exact-phrase + tags + type)×(1+semantic learned) + recency(temporal) + frecency + trust − all offline heuristics. Ordinal intent ("first/last/earliest/latest") adds a corpus-relative event-time boost.
5metadata filtersEnforced after rerank so graph-boosted ids can't leak past tags/type/trust/time filters.
6fallback scanRaw substring scan across stored text when the index returned nothing.
7evidenceDedup (Jaccard ≥ 0.85), contradictions, timeline, confidence summary; 4-way compression into the budget-aware CCR context with [ref: mem_N] anchors.
8sufficiency7 question types scored; below threshold → explicit [ABSTAIN].
9responseRecords + formatted_context + sufficiency metadata + usage counters; access counts bump without touching versions.
